# Creatine-Page 💪

Uma landing page informativa e responsiva sobre creatina, desenvolvida com HTML5 e CSS3 puro.

## 📋 Sobre o Projeto

Este projeto é uma página web educativa que apresenta informações completas sobre a creatina, incluindo seus benefícios, formas de uso, dosagem recomendada e tabela nutricional. A página foi desenvolvida com foco na experiência do usuário e responsividade.

## ✨ Funcionalidades

- **Navegação suave** entre seções com scroll behavior
- **Design responsivo** que se adapta a diferentes tamanhos de tela
- **Menu fixo** para fácil navegação
- **Seções informativas** sobre:
  - O que é creatina
  - Benefícios para o corpo
  - Como tomar e dosagem
  - Tabela nutricional completa
- **Links externos** para fontes confiáveis (ANVISA, estudos científicos)
- **Design moderno** com gradientes e efeitos visuais

## 🎨 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica da página
- **CSS3** - Estilização e responsividade
  - Flexbox para layout
  - Gradientes e sombras
  - Media queries para responsividade
  - Google Fonts (Outfit)
- **Imagens** - Otimizadas para web

## 🚀 Como Visualizar

1. Clone o repositório:
```bash
git clone https://github.com/Davilucca22/Creatine-Page.git
```

2. Navegue até a pasta do projeto:
```bash
cd Creatine-Page
```

3. Abra o arquivo `index.html` em seu navegador preferido

Ou simplesmente acesse: [GitHub Pages](https://davilucca22.github.io/Creatine-Page/)

## 📱 Responsividade

A página foi desenvolvida com design responsivo e se adapta a:
- **Desktop** (acima de 1250px) - Layout completo com imagens
- **Mobile/Tablet** (abaixo de 1250px) - Layout otimizado sem imagens
